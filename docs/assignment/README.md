# MultimediaAnalyzer Assignment Package

This folder integrates the software engineering assignment deliverables into the application repository.

Included artifacts:

- `requirements_analysis.md`
- `prioritized_requirements.csv`
- `use_case_diagram.mmd`
- `conceptual_model_class_diagram.mmd`
- `state_diagrams.mmd`
- `sequence_main_process.mmd`
- `activity_upload_and_analysis.mmd`
- `activity_watchlist_alerting.mmd`
- `ui_design_spec.md`
- `testing_strategy_and_cases.md`
- `ai_prototype_prompt.md`
- `test_report_template.md`

All `.mmd` files use Mermaid syntax and can be rendered in Mermaid-compatible tools or converted into PDF-ready images.
