# UI Design Specification

## Current Prototype Scope

The implemented UI is a responsive dashboard with:

- Hero section with product summary and account state
- Authentication card
- Upload card
- Watchlist configuration card
- Results feed with summaries, entity lists, transcript details, and alert status

## Visual Direction

- Clean, bright analyst dashboard
- Soft green palette to suggest analysis and signal
- Rounded panels with layered depth
- High-contrast action buttons
- Mobile-friendly stacked layout
