# AI Prompt For Function Prototype Construction

Use the following prompt for the extra-credit prototype task:

> Build a full-stack MVP called `MultimediaAnalyzer`. The system must support JWT authentication, media upload, background processing through Celery, PostgreSQL persistence, Redis broker usage, and a React/Next.js dashboard. For each uploaded audio or video file, the system should create a transcript, summary, named entities, and alert matches against a user-configured watchlist. Provide function prototypes and endpoint contracts for user registration, login, current-user retrieval, media upload, media listing, watchlist update, and asynchronous processing. Include SQLAlchemy models, Pydantic schemas, Celery task signatures, and frontend data contracts.

## Expected Prototype Outputs

- API endpoint signatures
- Service function signatures
- Task function signatures
- Data model contracts
- Frontend request/response types
